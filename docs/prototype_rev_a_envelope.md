# Prototype Rev A envelope — schematic design assumptions

2026-10-03 JST. Architecture adoption is approved by the user. This revision permits schematic work with explicit assumptions; it does not authorize energizing a prototype, full-power operation, PCB placement or a competition compliance claim. Earlier Task 3/4 holds on *schematic creation solely because physical conditions are unknown* are superseded by the current user instruction. Measurement and human review gates remain.

Every assumption below is **ASSUMPTION — MUST VERIFY ON PROTOTYPE**. Categories: A = prototype design assumption; B = measurement required before full power; C = hard inhibit/stop limit in the proposed design (not a demonstrated protection guarantee); D = tunable parameter. C values are **PROVISIONAL — MUST VALIDATE**, including errors and shutdown overshoot.

## Full-power gate

Before any energizing: independent schematic/pin/land-pattern review, source-current limiting and fault containment plan, cell monitor configuration readback/OTP plan, bank/source interruption review. Before full power additionally measure surge/regen/source impedance, gate ringing, bootstrap, port current, shutdown latency, all thermal paths, discharge and actual peak duty. A fuse holder or contact specification without verified DC breaking capability is not a fault-containment approval.
