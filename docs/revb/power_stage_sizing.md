# Rev B 電力段 仮選定(LM5170 CH-1 単相、バンク側13 A平均)

2026-10-10 ドラフト。**算術による仮選定であり、部品の品番・データシート値・実測は未確認。** LM5170の数値は[要件書6.2](requirements_and_architecture.md)(データシートのWebFetch要約)による。

## 1. 前提

- バス(HV側)22〜26 V、バンク(LV側)10〜20 V。バンク側の平均電流13 A、ピーク15 A以下(S184、CM01経由)。
- 単相(LM5170のCH-1のみ)、fsw=200 kHz。
- 保守的に、**インダクタ電流のピークをCM01経由のピーク電流とみなす**(バンク側コンデンサによるリップル吸収は見込まない)。

## 2. インダクタ

- 推奨: **12 µH(なければ10 µH)、200 kHz**。10 µHのピークは14.63 Aで余裕が小さいため、その場合は平均電流指令を12.5 A程度に下げる。
- 仕様の目安: 飽和電流 ≥ 22 A(15 Aの約1.5倍)、直流抵抗 ≤ 5 mΩ、高さは制御基板の目標(12 mm級)に収まるもの。品番は未選定(JLCPCBで探す)。

## 3. 電流検出抵抗とISET

- LM5170: VCS=0.02×V(ISETA)、ISETA=2.5 Vで検出電圧50 mV(データシート要約)。
- **3 mΩ(1%、4端子ケルビン、無誘導)**を仮選定。フルスケール電流=50 mV/3 mΩ=16.7 A。
- 13 Aのとき検出電圧39 mV → V(ISETA)=1.95 V → ISETDのPWMデューティ0.624(V=3.125 V×デューティ)。15 Aは45 mV → デューティ0.72。**ファームでデューティを0.624以下にクランプする**案。
- 抵抗の損失: 13 Aで0.51 W、15 Aで0.68 W。定格は余裕を見て2 W以上。

## 4. MOSFET(ハイサイド・ローサイド)

- 耐圧60 V(バス26 V+サージ余裕。TVSのクランプ電圧との関係は未確認)。
- オン抵抗 ≤ 8 mΩ(Vgs=10 V)、Qg ≤ 25 nC、5×6 mm級の熱パッド付きパッケージ。
- ゲート電圧: LM5170のVCC(9〜12 V)で駆動するので標準レベルでよい。ゲートドライバのピーク電流は5 A(データシート要約)。
- 品番は未選定。

## 6. LM5170の設定部品(データシート要約の式)

- 発振周波数: ROSC ≈ 40 kΩ×100 kHz/fosc → 200 kHzで約**20 kΩ**。
- デッドタイム: tDT ≈ RDT[kΩ]×4+16 ns → 50 nsで約**8.5 kΩ**(E96なら8.45 kΩ)。最大デューティ0.950(200 kHz)の前提。
- ブートストラップ: CBT ≥ 0.1 µFセラミック、DBT 1 A/100 V級の高速ダイオード、RBT 2〜5 Ω。
- VCC: 9〜12 V(バスから降圧して供給)、1〜2.2 µFのセラミックを近接。
- 1ch運用の終端: BRKG/BRKSは各20 kΩでAGNDへ。SYNCOUTの扱い(故障検出を無効にしてよいかは別途検討)。
- IPK抵抗(サイクルごとの過電流): データシートの式を原本で確認して決める。**未決**。

## 7. 未決・要確認

1. 各部品の品番(JLCPCBの在庫・価格)。
2. IPK抵抗値と、ピーク電流の許容誤差の積み上げ。
3. 底盤側の電流(入力・出力コネクタ、ヒューズ、銅箔)。未測定。
4. バンク側遮断(R1)のFET・ドライバ。2個直列のオン抵抗による損失も要検討(目安: 2×3 mΩで13 Aに約1 W)。
5. バンクの使用可能エネルギー: 20→10 Vで約75%。下限を下げるほど増えるが、10 V未満では13 Aでの電力が130 W未満になる。
