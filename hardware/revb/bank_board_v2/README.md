## クランプ電圧（算術）
Vc = Vref × (1 + 22.9k/20k) + Iref × 22.9k

| | 値 |
|---|---|
| 標準 | 2.66 V |
| 25℃ 最小〜最大 | 2.644〜2.687 V（Vref 1.234〜1.246 V、抵抗0.1%、Iref 最大0.5 µA） |
| 温度 | TLV431BQ の Vref 変動（全温度範囲で最大31 mV）分、さらに ±0.02 V 程度 |

充電 26.2 V（平均 2.62 V/セル）はクランプ最小値より低いので、バランスが取れていれば満充電でもクランプは作動しません。

## v1（`hardware/revb/bank_board/`）からの変更
1. **TLV431 のピン配置を修正**: TI SLVS139Z Table 4-1 では SOT-23(DBZ) は 1 = REF、2 = CATHODE、3 = ANODE。v1 の注記（1 = A、2 = REF、3 = K）のままだとクランプが動作しない。
2. **XT30 の極性を修正**: KiCad の AMASS フットプリントは pad1 = −。v1 は pin1 = + だった。
3. クランプ電圧を 2.61 → 2.66 V に変更（22.1k → 22.9k）。
4. PNP のベースに 100 Ω を追加し、TLV431 のカソード電流を約7 mA 以下に制限（絶対最大 20 mA）。
5. ヒューズ・セル・XT30 のフットプリントと JLC 部品番号を確定。
6. テストポイントは削除（セルのリード穴がそのまま測定点になる）。

## 製造
- `fab/bank_board_gerber.zip`、`fab/jlcpcb_bom.csv`、`fab/jlcpcb_cpl.csv`（**実装面 = Bottom**）。
- CPL の回転は制御基板と同じ補正表（JLCKicadTools）＋裏面の換算（kicad-jlcpcb-tools と同じ式）。JLC のプレビューで、Q（SOT-223）のタブ、U（SOT-23）の1番ピン、Q のエミッタ/ベースの向きを確認してください。

- セルの極性: シルクの斜線の半円が −、「+」印側が +。上段は右が +、下段は左が +。

## 未解決・要確認
1. **バイパス電流には上限がある**: 1セル当たり約0.6〜1.5 A（BCP69-16 の hFE 100〜250 × ベース電流約6 mA）、0.5 A で約1.3 W。容量のばらつきで一部のセルが先にクランプ電圧に達したとき、充電電流がこれを超えるとそのセルは 2.66 V を超えて上がり続ける。**満充電付近（例: バンク 25.5 V 以上）では、制御基板側で充電電流を 0.5 A 以下に絞る必要がある**（ファーム／設定で対応、未実装）。
2. PNP の発熱: 連続 1 W 以上は不可。タブを裏面のベタにつなぎ、ビアで表面のベタへ逃がしている。温度は実測が必要。
3. TLV431 + PNP のループ安定性は未検証（試作で発振を確認する。必要なら REF–K 間に補償容量を追加）。
4. セルのリード径: 穴径 1.2 mm で作っています。実物のリード径（一般に 0.8〜1.0 mm）を確認してください。
5. 取付穴: M3 ネジ頭はセル4本の間（空き直径約8.8 mm）に入る。ドライバーが届くか、実機の固定方法と合わせて確認。
6. XT30 はオス（制御基板 J102 と同じ）。ケーブルはメス–メス。電荷が残ったバンク側のピンが露出する点に注意。
7. KiCad 9 での DRC は未実施（KiCad 7 DRC: エラー0、未接続0。残りはライブラリ照合の警告のみ）。
